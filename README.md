# GPIO 무한 코드 연습

라즈베리파이 센서 시험 코드를 **랜덤 문제로 끝없이** 쳐 보며 익히는 사이트입니다.
부품 2개를 함께 쓰는 문제부터 시작해서 부품 수를 늘려 가고, 마지막엔 시험 종합 문제까지 풉니다.

## 연습 종류

### 부품별 연습
LED · LED 3개 · DC 모터 · 서보 · 거리 센서 · 온습도 센서 · 조도 센서 · LCD 중 하나를 골라
그 부품의 코드만 랜덤으로 연습합니다.

- **준비 코드 / 함수**: 예) `distance()` 함수, `read_lux()` 함수, `angle(a)` 함수, `led_on(pin)` 함수, DHT 만들기
- **짧은 프로그램**: 예) LED 0.5초 깜빡이, 선풍기 60% → 90% → 40%, 창문 45° → 135°, LCD 두 줄 표시
- LED 핀, 시간, 속도, 각도, LCD 문구가 매번 바뀝니다.

### 조합 문제 (단계)

| 단계 | 부품 수 | 예 |
|---|---|---|
| 1 | 2개 (센서 1 + 출력 1) | 온도가 27℃보다 높으면 LED 켜기 |
| 2 | 3개 | 거리가 가까우면 LED 켜고 창문 열기 / 온도·거리 둘 중 하나면 선풍기 |
| 3 | 4개 | 밝기로 LED 3색 + 온도로 창문 |
| 4 | 5개 | 온도로 선풍기 3단 + LCD에 밝기·거리 표시 |
| 5 | 종합 문제 | 시험 문제 코드 그대로, 기준 온도·속도 숫자만 랜덤 |

- 센서: 온습도(DHT22) · 거리(HC-SR04) · 조도(BH1750)
- 출력: LED · LED 3색 · DC 모터(선풍기) · 서보(창문) · LCD
- 조건 숫자, LED 핀, 속도, 각도, 조합이 매번 바뀌어서 문제가 끝없이 나옵니다.

## 보기 방식 (익숙해지는 순서)

1. **정답 보고 치기** — 정답 코드를 옆에 띄워 놓고 따라 칩니다.
2. **부품 조각만 보기** — 부품별 표준 코드 조각만 보고 한 프로그램으로 조립합니다.
3. **안 보고 치기** — 아무것도 안 보고 칩니다.

연속 정답은 2·3번 방식에서, 정답 보기·이 줄 보기를 쓰지 않았을 때만 올라갑니다.

3문제 연속으로 맞히면 다음 부품이나 다음 단계로 넘어가라는 안내가 나옵니다.

**추천 순서**: 부품별 연습(한 줄씩 확인) → 부품별 연습(전체 쓰기) → 조합 1~4단계 → 종합 문제

## 입력 방식

- **한 줄씩 확인** — 한 줄 치고 `Enter`를 누르면 그 줄이 맞는지 바로 알려 줍니다.
  - 들여쓰기는 앞 줄을 보고 자동으로 채워지고, `else:`처럼 밖으로 나갈 땐 `Backspace`로 4칸씩 지웁니다.
  - 내용은 맞는데 들여쓰기만 다르면 몇 칸이어야 하는지 알려 줍니다.
  - 두 번 틀리면 `imp▢▢▢ ▢▢▢▢▢` 같은 글자 수 힌트가 나오고, **이 줄 보기**로 정답 줄을 볼 수 있습니다.
  - `print(...)` 줄은 건너뛰어도 됩니다.
- **전체 쓰고 채점** — 전체를 다 쓴 뒤 `Ctrl + Enter`로 한 번에 채점합니다.

## 채점 (전체 쓰고 채점)

- 정답 코드의 모든 줄이 있고 들여쓰기(스페이스 4칸 단위)가 같으면 정답
- 줄 순서가 달라도 정답 (다르면 알려 줌)
- 띄어쓰기, `'`와 `"`, 주석, `True`/`g.HIGH`는 구별하지 않음
- `print(...)` 줄은 없어도 됨
- 틀린 줄은 `▢` 글자 수 힌트로만 보이고, **정답 보기**를 누르면 전부 보임

변수·함수 이름은 시험 코드와 같은 표준 이름을 씁니다:
`LED`, `LED_RED/GREEN/YEL`, `FAN`/`fan`, `SERVO`/`servo`, `TRIG, ECHO`, `dht`, `bus`, `lcd`, 값 `t h d lux`,
함수 `led_on`, `angle`, `distance`, `read_lux`.

## GitHub Pages로 올리기

1. GitHub에서 **New repository** → 이름 예: `gpio-infinite` → **Public** → Create
2. **Add file → Upload files** → `index.html`, `README.md` 올리기 → **Commit changes**
3. **Settings → Pages** → Branch **main** / 폴더 **/(root)** → Save
4. 1~2분 뒤 `https://내아이디.github.io/gpio-infinite/` 로 접속

파일 하나(`index.html`)로 동작하므로 더블클릭해서 바로 열어도 됩니다.
기록(단계별 정답 수, 연속 정답)은 그 브라우저에만 저장됩니다.

## 키

- `Ctrl + Enter` 채점
- `Tab` 들여쓰기, `Shift + Tab` 내어쓰기
- `Enter` 뒤 들여쓰기 자동 (`:` 다음엔 한 단계 더), 공백만 있을 때 `Backspace`는 4칸씩 지움
